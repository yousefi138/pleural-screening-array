Background

Noted in ewas-summary.html that reported age and smoking status did not show any significant associations with DNAm, but DNAm-estimated age and DNAm-estimated smoking status did.

Purpose

The purpose of this analysis report is to compare the EWAS results for reported vs. DNAm-estimated age and smoking variables to see if they’re comparable.
